# USB受信音声・CW送信インターフェース仕様（Rev.A v0.2.0）

更新：2026-11-05。**設計仕様であり、実機制御は未実装・未検証。**

## 基本方針

- PC（Windows）上でUSB Audioの受信、CW復号、QSO状態制御、送信テキスト生成、ログ・得点計算、提出ファイル生成まで完結させる。
- 標準構成には独立MCU基板、外付けキーヤー、CWデコーダー、専用音声インターフェースを**含めない**。
- USB AudioとUSBシリアル/CI-V/CWキーイングを無線機内で同時利用できる機種は**USBケーブル1本**とする（例：IC-7300。ただし設定と機種別検証が必要）。
- USB音声でCWトーンを送ることはA1Aのキーイングに相当しない。**CWはCI-Vまたはキーイング機能で生成する**。
- 内蔵USB音声がない機種は外付けUSBオーディオが必要になる。これは「PC以外にハードウェア追加なし」の対象外として対応可否を分ける。

## 経路

```
[無線機] --USB Audio (受信AF)--> [PC: 音声DSP/モールス復号]
                                        |
                               [自動QSO状態機械]
                                        |
                              [送信テキスト・停止制御]
                                        |
      ┌─────────────────────────────────┼────────────────────────┐
      |                                 |                        |
  (第一候補)                        (第二候補)                (代替手段)
CI-V CW文送信(17h)              USB仮想COM DTR/RTS          USB小型KEYユニット
      |                                 |                        |
[無線機のCW発生]               [無線機内蔵キーイング]        [CW KEY端子]
      └─────────────────────────────────┴────────────────────────┘
                                        |
                              [無線機によるA1A送信]
```

## 送信アダプターの優先順位

1. `icom_civ_cw`: **CI-V コマンド `17h`**。無線機内蔵のCW送信機能に文字列を渡す。IC-7300公式CI-V資料では**最大30文字**、**`FFh`で中断**。CWモード、送信可能状態、ブレークイン等の設定確認が必要。文字列を短く分割する場合、無線機内での送出完了を単にCI-V ACKから推定しない。再送による二重送信を避ける。
2. `usb_serial_dtr_rts`: 無線機がUSB仮想COMポートのDTR/RTSをCWキーイング入力に割り当てられる場合。**外部インターフェースは不要**。ただしPC OSスケジューリングのジッター、COMポートオープン時のDTR/RTS一時アサートを考慮。安全確認なしで開始しない。CI-V制御とライン制御のポート共有可否は機種別に検証。
3. `external_usb_key`: それらに非対応の機種で、**専用の簡易USBキーイングユニット**から、無線機の外部KEYジャックへ接点相当の出力を与える。USB-UARTの出力をKEYジャックへ直結しない。キー接点の極性・電圧・電流、ストレートキー/パドル設定、絶縁・ブート時の誤送信対策を機種別に確認。外付けユニットは任意であり、第一候補には含めない。

## 無線機設定（IC-7300を例とする暫定プロファイル）

- 受信AF: USB Audio（USBからのAF出力設定を確認。USB IF出力とは区別）。
- 制御: USB上の仮想COM、USBシリアル機能はCI-V、CI-Vアドレス/通信速度は実機設定と一致させる。
- CI-V CW: `17h` コマンド。符号の実送信は無線機側。CW、BK-INなどの実際の動作条件を検証する。
- DTR/RTS CW: 機器設定の「USB Keying (CW)」でDTRまたはRTSを選択。CI-V方式を使用する場合は原則OFF。USB SENDと重複割当しない。
- `USB Keying (CW)` 設定と `CI-V command 17h` は**別方式**であり、同時送信しない。
- `KEY SPEED` 等の送信速度をCI-Vで設定できる機種でも、制御前に現行値を取得・保存し、終了時に復元する。

## 安全条件とログ

- 起動時、無線機接続直後、異常時、操作停止時は送信禁止を既定にし、接続・周波数・CWモード・使用バンド・送信経路を確認してから有効化する。
- 停止ボタン/ESCでソフトウェア送信キューを止め、使用中の経路のキャンセル処理を実行する。**ハードウェアKEY端子接点の強制開放と、CI-Vメッセージ停止は同義でない**ため個別に検証する。
- 無線機側のタイムアウトタイマー、USBキーイング開始時の誤送信防止機能を可能なら有効化。USB切断・プロセス終了・OSサスペンド時の振る舞いは実機で確認する。
- CW受信不確実、複数局同時呼出し、ナンバー欠落の場合はQSO確定・送信を自動で続行しない。承認なしの自律運用はJARL規約適合性の確認まで提供しない。
- 元の受信文字列、判定信頼度、送信したメッセージ、運用周波数、機種、送信経路、オペレーター介入を時刻付きで記録。
