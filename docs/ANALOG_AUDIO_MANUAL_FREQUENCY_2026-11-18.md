# アナログ音声入力・手動固定周波数・外付けUSB KEYインターフェース設計

状態: **設計のみ / 未実装 / 未実機検証**。基準: v0.7.0（IC-7300 USB）。IC-705等の機種対応・機種識別・既存SQLite集計を維持し、CI-Vのない運用を追加する。更新日: 2026-11-18。

## 基本方針

受信音声、周波数/モード取得、CW送信を独立した三つのバックエンドへ分離する。

| 構成要素 | 既定 | 代替 |
|---|---|---|
| ReceiveAudio | 無線機USB Audio | 無線機PHONES/SP/高インピーダンスAF→PC LINE INまたはUSB音声入力 |
| RadioState | CI-Vで周波数・モード取得 | ユーザーが周波数・CW/CW-R・バンドを手動設定して「固定」 |
| Keying | 対応確認済のCI-V 17h | USB接続KEYインターフェース→無線機CW KEY端子 |

**CW A1A送信はPC音声でトーンを送る方式と混同しない。** 受信AFはモールス解読用。CI-Vメッセージまたは物理KEY接点で送信する。アナログ方式でも無線機自身はCWモードに設定し、ブレークイン条件を人間が確認する。

## 対象と接続

- IC-7300: PHONES 3.5mm stereo / CW KEY 6.35mm。外付けキーヤーはCW-KEY SETでKeyer Type = Straight（公式マニュアル）。
- IC-705: [SP/MIC]のSP側3.5mm音声 / CW KEY 3.5mm stereo。Key Type=Straight、CWのBK-INを設定。IC-705のSPは独立ヘッドホン端子と呼ばずSP/MICと表示する。
- その他ICOM機種: 機種別公式取扱説明書でAF出力種別・定格、KEY端子の形状/配線/接点電圧/最大電流/内蔵キーヤー設定を確認した後に利用可能とする。普遍的なジャック仕様は仮定しない。
- PCがLINE INを備えない場合は、録音入力対応の汎用USBオーディオインターフェースを選択する。マイク入力しかない場合は適切な減衰・バイアス分離/必要に応じて絶縁を行い、PCマイク用電源や過大入力を直接接続しない。
- ヘッドホン/SP出力は音量ノブに連動する場合があり、録音レベルとクリッピングを監視する。外部スピーカー出力はより高レベルであり、安易にPC MIC/LINE入力へ直結しない。高インピーダンスAF/ACC定電圧出力が利用できるなら優先候補。

## モード定義

1. `AUTO_CIV_USB`: USB Audio + USB CI-V + 対応17h
2. `CIV_WITH_EXTERNAL_KEY`: USBまたはBluetooth SPP CI-V + 別途USB KEY
3. `ANALOG_FIXED`: PC LINE IN/USB録音入力 + 手動固定周波数 + USB KEY。CI-Vを一切必須としない。
4. `AUDIO_ANALOG_CIV`: PCアナログ入力 + CI-V周波数/モード + 対応17hまたはUSB KEY。

設定UIは3つの独立ドロップダウン（**受信音声**／**周波数・モード情報源**／**CW送信方法**）とし、互換性を検査する。Wi-Fiは現行の通常選択肢に加えない。

## 画面と状態

- 情報源が「手動固定」のとき、周波数(Hz、例 7.015000 MHz)、モード(CW/CW-R)、コンテスト、固定中フラグ、ユーザー確定日時を必須入力とする。
- 「手動固定」ではCI-Vがないため機種照合 `19 00` を実行できない。「無線機確認」欄には **未確認（手動固定）** と明示し、機種を自動識別済みと表示しない。録音入力のレベル・USB KEYの無送信状態チェックは別の接続診断として実行できる。
- 手動の周波数変更で所属バンドを再判定し、受信候補と交信済み局フィルターを更新する。変更時、選択中QSOは再確認する。別バンドの交信済み局は再交信候補にできる。
- **手動設定と無線機実周波数の一致は保証できない。** ダイヤル変更を自動検出できないため、ユーザーが変更ごとに明示更新する。「手動確認済み」「CI-V実測」「不明/旧値」を厳密に分け、提出ログへ使用する周波数の根拠と確定時刻を保存する。
- ログデータは既存SQLiteを正本として保持し、重複判定キーはコンテスト開催ID + バンド + コールサイン。CW固定モードでも同じルールを適用。
- 手動固定モードの強制終了条件は、キーインターフェースの切断、音声入力喪失、実行中止、タイムアウト。CI-V値の更新失敗は手動モードでは検査対象にしない。

## CW KEYの安全性

- USB-シリアルのDTR/RTS直結は不可。無線機KEY入力に適合する、ノーマルオープンのトランジスタ/フォトカプラ/PhotoMOS等で接点をエミュレートする。外部インターフェースの電気定格・絶縁・極性は機種別に確認する。
- WindowsでDTR/RTSを直接タイミング制御すると遅延・ジッタが生じ得るため、**コンテスト自動送信では小型USBキーヤー内部で短点・長点時間を生成する方式を優先**。より簡単なDTR/RTS方式は試験/代替用。
- 初回接続・再接続・エラー時の出力OFFを保証する設計。アプリ側ARM操作前は送信禁止。長時間KEY ONに備えた独立ウォッチドッグ/タイムアウト、即時ABORTと手動停止を用意。
- Break-in設定確認、KEY端子仕様、送信出力制限、実周波数/モードの手動確定なしに無人自動送信を有効化しない。JARL完全自律参加の扱いも別途公式確認が必要。

## 音声を通したCW復号時の注意

- サイドトーン等の自局送信音をCQに対する呼出と誤認しないよう、送信キーONから受信再開までデコーダ入力をゲート/タグ付けする。
- LINE INの入力レベルメーター、ピーク/クリップ警告、左右チャンネルの選択、音声のバンドパス、録音デバイスの消失検知を備える。
- パイルアップでは全局分離は行わず、選択した一局を追跡する既定の設計を維持。

## 検証項目（すべて未実施）

1. USBオーディオのみ・CI-Vなしで入力デバイスを選び、周波数固定・CWモード固定・ログ作成を模擬動作。
2. 7MHz→14MHz→7MHzの手動変更で交信済みフィルターが正しく切り替わること。
3. 入力音声の過大入力/無音/ケーブル抜け/PCサンプルレート変動時の安全挙動。
4. USB KEY電源投入・抜き差し・アプリ強制終了でもKEY端子が閉じっぱなしにならないこと。
5. IC-7300 KEY 6.35mm / IC-705 KEY 3.5mmのピン配置および必要電気特性を実測/公式図と照合し、ダミーロードで送信試験。
